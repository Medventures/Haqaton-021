## Проблема

Родители детей с РАС теряются между медициной, образованием и соцзащитой и по нескольку раз собирают одни и те же документы. Специалисты каждой системы видят только свой фрагмент и не видят маршрут ребёнка целиком. Из-за этого ребёнок позже получает помощь.

## Решение

> «Мы не создаём ещё одну медицинскую систему. Мы соединяем существующие системы вокруг ребёнка».

Веб-платформа на русском и казахском языках: **AI-интервью → межведомственный Case Plan → куратор по подписке → контроль сроков → эскалация просрочки**, а вокруг маршрута — календарь, хранилище документов и проверенные специалисты.

1. **Регистрация.** Родитель или специалист регистрируется по почте и паролю. При регистрации принимается Пользовательское соглашение и отдельно даётся согласие на обработку персональных данных, в том числе данных о здоровье ребёнка. Факт, версия, время и IP сохраняются.
2. **AI-интервью (8–12 вопросов).** Какие вопросы нужны, решают правила в коде, а OpenAI формулирует вопросы на языке пользователя и извлекает факты из свободного ответа, в том числе на казахском («2 жас 4 ай» = 28 месяцев). На признаки потери навыков, самоповреждения, агрессии или судорог сразу показывается сообщение о враче и номер 103. Администратор меняет формулировки на двух языках, порядок вопросов и добавляет свои.
3. **Case Plan — одна JSON-структура.** Шаги берутся только из справочника услуг, модели передаётся `z.enum` допустимых `serviceId`. У каждого шага есть приоритет, ответственный, срок, документы, статус, история и объяснение на двух языках. Guard отсеивает диагнозные формулировки на русском и казахском. Справочник и системный промт опираются на клинический протокол МЗ РК №145 от 30.07.2021 (РАС): M-CHAT-R в 2 года, диагноз ставит психиатр, обязательная проверка слуха при задержке речи, заключение ВКК для ПМПК и МСЭ, немедикаментозные программы. AI не упоминает лекарства и не ставит диагноз.
4. **Без куратора — бесплатно.** Маршрут от AI открывается сразу, родитель сам ведёт статусы и сроки. Календарь, хранилище, каталог специалистов и отзывы доступны без подписки.
5. **Куратор по подписке.** Тестовая оплата, отдельное Соглашение об услугах куратора. Куратор назначается автоматически, проверяет и правит маршрут, подтверждает его (до подтверждения семья видит маршрут только если он был открыт до подписки), ведёт статусы, получает эскалации: просрочка — уровень 1, больше 7 дней — «Эскалация руководителю службы». У куратора есть доступ к хранилищу и календарю семьи.
6. **Календарь.** Приёмы пищи, тренировки, занятия со специалистами, приёмы врачей, лекарства, режим, с повтором по дням и неделям. Общий у семьи и куратора.
7. **Хранилище.** Фото и документы ребёнка (PDF, Word, Excel, изображения до 10 МБ). Документ можно связать с документом маршрута — он отметится готовым во всех шагах.
8. **Специалисты.** Анкеты нянь, тренеров АФК, нутрициологов, врачей, логопедов, дефектологов, психологов, АВА-терапевтов и других. Анкета публикуется после проверки комиссией, отзывы родителей — после модерации.
9. **Юридические документы.** Пользовательское соглашение (публичная оферта), Согласие и политика обработки персональных данных (Закон РК «О персональных данных и их защите»), Соглашение об услугах куратора — на русском и казахском.

## Запуск

Требования: Node.js 22.

```bash
npm install
cp .env.example .env
npm run db:push
npm run db:seed
npm run dev
```

Приложение: http://localhost:3000. База — SQLite-файл `prisma/aqylroute.db` рядом с проектом.

Переменные окружения:

| Переменная | Назначение |
|---|---|
| `OPENAI_API_KEY` | Ключ OpenAI. Без него интервью и маршрут работают на правилах |
| `OPENAI_MODEL` | Модель, например `gpt-4.1-mini` или `gpt-5.5` |
| `OPENAI_BASE_URL` | Необязательно, свой endpoint OpenAI API |
| `SESSION_SECRET` | Секрет подписи сессии, случайная строка от 32 символов |
| `SEED_PASSWORD` | Пароль тестовых аккаунтов, по умолчанию `Aqyl2026!` |
| `RESEED_ON_START` | `true` — пересоздавать демо-данные при каждом запуске |
| `DEMO_RULES_ONLY` | `true` — работать только на правилах, без OpenAI |

Проверки:

```bash
npm run lint
npm run build
npm start
BASE_URL=http://localhost:3000 npm run test:flow
```

`test:flow` прогоняет сценарии через API: регистрация с согласиями, интервью на русском и казахском, маршрут без куратора, покупка подписки и назначение куратора, подтверждение плана, эскалации, календарь, хранилище и доступы, заявка специалиста и решение комиссии, отзыв и модерация, вопросы администратора, юридические страницы.

## Деплой на Railway

Приложение развёрнуто на Railway по ссылке из раздела «Демо». Переменные окружения из таблицы выше задаются в настройках сервиса. Команда запуска проекта — `npm start`: `prisma db push` → создание аккаунтов и демо-данных, если база пустая → `next start`.

## Что готово

- Регистрация родителя и специалиста, вход по паролю, шесть ролей: родитель, куратор, специалист, комиссия, модератор, администратор.
- Весь интерфейс, справочник, вопросы интервью, объяснения AI и юридические документы на русском и казахском.
- AI-интервью с адаптивными вопросами, fallback на правила, red flags, отмена ответа, админка вопросов.
- Case Plan по справочнику и клиническому протоколу №145, без диагнозов, в одной JSON-структуре с историей изменений.
- Режим без куратора и подписка на куратора с подтверждением плана, контролем сроков и эскалациями.
- Календари семьи и куратора, хранилище документов и фото с доступом куратора.
- Каталог специалистов, проверка анкет комиссией, отзывы с премодерацией.
- Пользовательское соглашение, согласие на обработку персональных данных, соглашение об услугах куратора, фиксация согласий.
- Онлайн-демо на Railway с автоматическим созданием тестовых аккаунтов всех ролей при первом запуске.

Известные ограничения:

- Оплата подписки тестовая, реальный платёжный шлюз не подключён.
- SQLite хранится в файловой системе контейнера Railway. Без постоянного тома данные и загруженные файлы могут потеряться при пересоздании контейнера.
- Реквизиты оператора в юридических документах — заглушки. Перед запуском тексты должен проверить юрист.
- Справочник услуг и сроки демонстрационные, в продакшене выверяются с ведомствами.
- Уведомлений по SMS и email нет, эскалации видны в кабинете куратора.
